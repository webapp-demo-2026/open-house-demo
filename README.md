# open-house-starter

Template Repository ของ Lab 8 (จำลอง Scrum) — หน้าเว็บประชาสัมพันธ์งานวันเปิดบ้านของสาขา

## วิธีใช้
1. กดปุ่ม **Use this template** → **Create a new repository** ตั้งชื่อ `open-house-<ชื่อกลุ่ม>`
2. เชิญสมาชิกกลุ่มทุกคนเข้า Repository (Settings → Collaborators)
3. เปิดโฟลเดอร์ใน VS Code แล้วเปิด `index.html` ด้วย Live Preview

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ มีคอมเมนต์บอกตำแหน่งของแต่ละรายการ (US-xx) |
| `style.css` | รูปแบบของทุกส่วนเตรียมไว้แล้ว ทีมเขียนเฉพาะ HTML |
| `docs/backlog.md` | Product Backlog 8 รายการ เรียงลำดับแล้ว พร้อม Acceptance Criteria |
| `docs/definition-of-done.md` | Definition of Done ตั้งต้น ให้กลุ่มตกลงก่อนเริ่ม Sprint 1 |
| `docs/po-card.md` | บัตร PO: Product Goal ข้อมูลของงาน และเหตุผลของลำดับ |

ข้อมูลของงานทั้งหมดเป็นข้อมูลสมมติสำหรับ Lab
