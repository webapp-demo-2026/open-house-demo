# Product Backlog — หน้าเว็บวันเปิดบ้าน (เรียงลำดับโดย PO แล้ว)

แต่ละรายการมีรหัส US-xx รูปแบบ User Story และ Acceptance Criteria (AC) ที่ใช้ตรวจตอน Sprint Review
ข้อมูลที่ต้องใส่บนหน้า (วัน เวลา ห้อง กำหนดการ) อยู่ในบัตร PO (`docs/po-card.md`)
บรรทัด "ชื่อการ์ด" คือข้อความที่ PO วางลง Project Board

## 1. US-01 ส่วนหัวของงาน
ชื่อการ์ด: US-01 ส่วนหัวของงาน
ในฐานะนักเรียน ม.6 ที่สนใจสาขา ฉันต้องการเห็นชื่องาน วันที่ เวลา และสถานที่ทันทีที่เปิดหน้า เพื่อตัดสินใจได้เร็วว่าจะมาร่วมงานได้หรือไม่
- [ ] ส่วนหัว (`<header class="hero">`) แสดงชื่องานเต็มตามบัตร PO
- [ ] ใต้ชื่องานมีวันที่ เวลา และสถานที่ (ใช้ `<p class="when">`) ตรงกับบัตร PO
- [ ] เห็นครบทั้งสามอย่างโดยไม่ต้องเลื่อนหน้า บนจอกว้าง 1280 px

## 2. US-02 กำหนดการ
ชื่อการ์ด: US-02 กำหนดการ
ในฐานะผู้ปกครอง ฉันต้องการเห็นกำหนดการเป็นช่วงเวลา เพื่อวางแผนการเดินทางไปและกลับ
- [ ] มีหัวข้อ "กำหนดการ" และตาราง `<table class="schedule">` 3 คอลัมน์ เวลา | กิจกรรม | สถานที่
- [ ] มีครบ 4 ช่วงเวลาตามบัตร PO เรียงจากเช้าไปบ่าย
- [ ] ตารางอยู่ใน `<div class="table-wrap">`

## 3. US-04 ลงทะเบียนเข้าร่วม
ชื่อการ์ด: US-04 ลงทะเบียนเข้าร่วม
ในฐานะนักเรียนที่ตัดสินใจมาแล้ว ฉันต้องการลงทะเบียนได้จากหน้านี้ เพื่อให้สาขาเตรียมที่นั่งในห้องทดลองเขียนเว็บให้
- Given ผู้ชมเปิดหน้าอยู่ที่ส่วนหัว When คลิกปุ่ม "ลงทะเบียนเข้าร่วม" Then หน้าเลื่อนลงไปที่ส่วน `id="register"`
- Given ผู้ชมอยู่ที่ส่วนลงทะเบียน When อ่านข้อความ Then เห็นวันปิดรับลงทะเบียน (9 มกราคม 2570) และลิงก์ไปแบบฟอร์มตามบัตร PO

## 4. US-03 จุดเด่นของสาขา
ชื่อการ์ด: US-03 จุดเด่นของสาขา
ในฐานะนักเรียนที่กำลังเลือกสาขา ฉันต้องการรู้จุดเด่นของสาขาแบบสั้น ๆ เพื่อเทียบกับสาขาอื่นที่สนใจ
- [ ] มีหัวข้อ "จุดเด่นของสาขา" และการ์ด 3 ใบใน `<div class="cards">` แต่ละใบใช้ `class="card"`
- [ ] แต่ละใบมีหัวเรื่อง (`<h3>`) และคำอธิบาย 1–2 ประโยค ตรงกับจุดเด่น 3 ข้อในบัตร PO
- [ ] บนจอกว้าง 1280 px การ์ดเรียงเป็นแถวเดียว 3 ใบ

## 5. US-05 การเดินทาง
ชื่อการ์ด: US-05 การเดินทาง
ในฐานะผู้ปกครองที่ขับรถมาส่ง ฉันต้องการรู้ว่าอาคารอยู่ตรงไหน เพื่อมาถึงทันเวลาลงทะเบียนหน้างาน
- [ ] มีหัวข้อ "การเดินทาง" ชื่ออาคาร ชั้น และห้องตามบัตร PO
- [ ] มีลิงก์ "เปิดแผนที่" ที่เปิดในแท็บใหม่ (`target="_blank"`) ระหว่างจำลองใช้ที่อยู่ https://www.openstreetmap.org/

## 6. US-08 ใช้บนมือถือได้
ชื่อการ์ด: US-08 ใช้บนมือถือได้
ในฐานะนักเรียนที่เปิดลิงก์จากโทรศัพท์ ฉันต้องการอ่านทุกส่วนได้บนจอเล็ก เพื่อไม่ต้องย่อขยายหน้า
- Given เปิดหน้าใน Device Toolbar ของ DevTools ที่กว้าง 375 px When เลื่อนจากบนลงล่าง Then ทั้งหน้าไม่มีแถบเลื่อนแนวนอน
- Given ความกว้างเดียวกัน When ดูส่วนกำหนดการ Then อ่านตารางได้ครบ (ถ้าตารางกว้างเกิน ให้เลื่อนเฉพาะในกรอบของตาราง)

## 7. US-06 คำถามที่พบบ่อย
ชื่อการ์ด: US-06 คำถามที่พบบ่อย
ในฐานะผู้ปกครอง ฉันต้องการอ่านคำตอบของคำถามที่ถามบ่อย เพื่อไม่ต้องโทรถาม
- [ ] มีหัวข้อ "คำถามที่พบบ่อย" ใน `<section class="faq">` และคำถาม 3 ข้อ (คำถามเป็น `<h3>` คำตอบเป็น `<p>`)
- [ ] คำถามอย่างน้อย 1 ข้อเรื่องค่าใช้จ่าย (ตอบว่าไม่มีค่าใช้จ่าย)

## 8. US-07 ติดต่อสอบถาม
ชื่อการ์ด: US-07 ติดต่อสอบถาม
ในฐานะผู้ชมที่มีคำถามอื่น ฉันต้องการเห็นช่องทางติดต่อ เพื่อสอบถามเจ้าหน้าที่ได้
- [ ] ส่วนท้าย (`<footer>`) มีอีเมลเป็นลิงก์ `mailto:` และเบอร์โทรตามบัตร PO
