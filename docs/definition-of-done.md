# Definition of Done (DoD) ตั้งต้น — กลุ่มตกลงหรือแก้ก่อนเริ่ม Sprint 1

รายการใน Product Backlog จะนับว่า "เสร็จ" (เป็นส่วนหนึ่งของ Increment) ได้ เมื่อผ่าน ทุกข้อ ด้านล่าง และผ่าน Acceptance Criteria ของรายการนั้นใน `backlog.md`

1. โค้ดอยู่ในสาขา `main` ของ Repository กลุ่มบน GitHub แล้ว (commit และ push แล้ว)
2. เปิด `index.html` ใน Chrome แล้วแท็บ Console ของ DevTools ไม่มีข้อความสีแดง (error)
3. ข้อความภาษาไทยบนหน้าตรงกับข้อมูลในบัตร PO ไม่มีคำผิด
4. เพื่อนในกลุ่มอีก 1 คนเปิดหน้าดูบนเครื่องของตัวเองแล้วตรวจ Acceptance Criteria ครบ
5. การ์ดของรายการนั้นบน Project Board อยู่ในคอลัมน์ Done

กลุ่มแก้ข้อใดหรือเพิ่มข้อใด ให้แก้ไฟล์นี้แล้ว commit ก่อนเริ่ม Sprint 1 และใช้ฉบับเดียวกันทั้ง 2 Sprint
